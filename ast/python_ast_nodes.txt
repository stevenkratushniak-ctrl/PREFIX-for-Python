This is the complete, finite set of AST node types.
All valid Python programs are compositions of these nodes.

====================================================
GLOBAL RULE
====================================================

All Python programs at version 3.12 are finite compositions
of the above node types under grammar-enforced constraints.

No other node types exist.
Any attempt to express structure outside this registry
is invalid and must be rejected or transformed.
