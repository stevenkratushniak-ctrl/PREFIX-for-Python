# Rename Decision

## Recommendation

Launch the product publicly as `PREFIX for Python`.

## Why `PREFIX` Wins

- `AutoFix` sounds post-failure and reactive.
- `PREFIX` describes the real operating boundary: before invalidity and before execution.
- `PREFIX` better supports a premium infrastructure posture.
- `PREFIX` leaves room for future language-specific wedges without diluting the philosophy.

## What Stays the Same

- deterministic correction
- finite grammar theory
- refusal semantics
- anti-hallucination posture
- local-first execution
- bounded error surface
- operational certainty

## Naming Line

Use this sentence consistently:

`PREFIX for Python is a deterministic Python prefix layer for bounded correctness.`
