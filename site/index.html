What It Does

PREFIX accepts a narrow and explicit product boundary. If the state belongs to a finite deterministic class, it prefixes the lawful continuation. If not, it stops and says so.

What It Corrects

  • Missing block colons
  • Missing indentation
  • Empty required blocks
  • Simple unmatched delimiters
  • Singular extra closing delimiters

What It Refuses

  • Ambiguous syntax repair paths
  • Orphaned `else` branches
  • `return` outside a function
  • Unsupported structural failures
