# CUSTOMER ONE-PAGER

## PREFIX for Python

Deterministic Python prefix layer for bounded correctness.

## Release Posture

Controlled founding-operator release for selected engineers and teams.

## What It Does

`PREFIX` accepts a finite admissible class of Python structural failures, applies one lawful deterministic correction when it exists, and refuses everything ambiguous or unsupported.

## Why It Matters

- fewer invalid edits survive long enough to waste review time
- less debugging time is burned on structurally broken states
- automated mutation becomes safer because guessing is off the table
- receipts, rollback, inspection, and replay create operational trust

## What Makes It Different

- not probabilistic
- not ranking-based
- not best effort
- not AI assistant software
- local-first
- refusal-capable
- replayable
