## Launch Description

PREFIX Python is a deterministic structural-governance runtime for selected Python engineering teams.

It is built for bounded structural governance, proof surfaces, replay, and explicit refusal.

When one lawful continuation exists, PREFIX applies a bounded governed mutation, validates it, and produces proof.

When the transition is ambiguous, unsafe, semantic, or unsupported, PREFIX advises, analyzes, or refuses without hidden mutation.

This release is available through a Private Operator Release for selected engineering teams. Evaluation access is 30 days and includes proof-driven onboarding.

Runtime support is intentionally pinned for rc2. Python `3.11`, `3.13`, and `3.14` are not claimed. Python `3.13` and `3.14` require separate AST authority catalogs before support can be claimed.
