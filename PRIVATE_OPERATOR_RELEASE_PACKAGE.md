## 2. Private Release Page Copy

### Hero Headline

Deterministic structural governance for Python transitions.

### Subheadline

PREFIX Python helps engineering teams reduce repetitive debugging loops, unsafe mutations, and AI-generated patch drift by governing Python changes before they become runtime failures.

### Problem

Python teams lose time to the same preventable failure loops:
- code mutates without proof
- review discovers structural breakage too late
- AI-generated changes drift across files without replayable evidence
- developers fix the same syntax and structure failures repeatedly
- debugging cycles expand because the system cannot explain what changed

The cost is not just a syntax error. The cost is interruption, review churn, lost confidence, and repeated recovery work.

### Product

PREFIX Python is a deterministic structural-governance runtime for Python transitions.

It evaluates a Python change as a transition request:

Human intent -> bounded structural analysis -> admissible continuation mapping -> deterministic transition governance -> legality evidence -> proof-bearing mutation or refusal.

When one lawful continuation exists, PREFIX applies a governed mutation and records evidence.

When the state is ambiguous, unsafe, semantic, or unsupported, PREFIX refuses or advises without mutation.

### Four-State Model

**APPLY**

One lawful continuation exists. PREFIX applies the bounded mutation, validates parse/reparse, records legality evidence, and produces replayable proof.

**ADVISE**

Multiple or candidate continuations can be ranked deterministically. PREFIX shows the admissible continuations and performs zero automatic mutation.

**ANALYZE**

The structure can be explained, but mutation would require unsafe invention or unsupported authority. PREFIX identifies the boundary and performs zero mutation.

**REFUSE**

The transition is unsupported, unsafe, or outside the bounded Python surface. PREFIX refuses deterministically and performs zero mutation.

### Proof And Replay

Every accepted mutation is evidence-bearing:
- legality score
- governing law
- continuation graph
- witness root
- AST/token hashes
- receipt inspection
- deterministic replay
- rollback readiness where the pre-image is valid

The point is not to make the editor feel clever.

The point is to make mutation accountable.

### FAQ

**Is PREFIX an AI coding assistant?**

No. PREFIX is deterministic structural governance for Python transitions.

**Does PREFIX generate code?**

No. It applies only bounded governed mutations when one lawful continuation exists.

**What happens when there are multiple possible continuations?**

PREFIX enters ADVISE. It may rank continuations deterministically, but it does not mutate automatically.

**What happens when a change is unsafe?**

PREFIX analyzes or refuses. Refusal is a valid trust-preserving outcome.

**Does PREFIX replace linters?**

No. Linters report problems. PREFIX governs certain Python transitions before they become downstream failure loops.

**Is this free forever?**

No. The 30-day evaluation is for selected teams. Continued commercial use requires a paid license.
