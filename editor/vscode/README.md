# PREFIX for Python

**Stop certain Python mistakes before they become errors.**

PREFIX for Python is a local deterministic correction engine for a bounded set of Python 3.12 structural mistakes. When one mapped safe continuation exists, PREFIX can apply it. When a correction is ambiguous, semantic, unsupported, or outside the qualified boundary, PREFIX refuses to guess.

## Commercial model

PREFIX is one product: **$29 once**. The VS Code extension is a free interface to the locally installed PREFIX engine. A legitimate PREFIX entitlement is shared by the CLI and supported editor adapters; you do not buy a separate VS Code license.

This pre-publication branch does not contain the production Lemon Squeezy product IDs or checkout URL.

## Commands

- `PREFIX: Govern Active Python Transition`
- `PREFIX: Govern Selected Python Structure`
- `PREFIX: Show Last Transition Governance Surface`
- `PREFIX: License Status`
- `PREFIX: Activate License`
- `PREFIX: Deactivate This Installation`
- `PREFIX: Buy PREFIX — $29 Once`

Activation accepts the purchased license key through a password-style input box. No JSON editing is required.

## Local-first behavior

Correction source is processed by the local PREFIX engine. Correction transactions do not wait on Lemon Squeezy. Activation requires network access; a successfully established entitlement is cached locally under the PREFIX entitlement policy.

Licensing determines whether commercial correction may run. Licensing never chooses, ranks, or changes a Python correction.

## Compatibility

PREFIX for Python 0.1.0 is limited to CPython 3.12.x. Qualified packaged platforms are Windows x64 and Linux amd64. macOS, ARM64, Python 3.11, 3.13 and 3.14 are not claimed by 0.1.0.

## Limitations

PREFIX is not a semantic code generator or general debugger. Unsupported states are intentionally refused.

## Privacy

Python source is not sent to Lemon Squeezy. License activation/validation sends the license key and a random PREFIX installation label required for licensing. PREFIX does not use a hardware fingerprint for entitlement identity.
