# Privacy

PREFIX corrections run in the locally installed Python engine. Python source is not sent to Lemon Squeezy.

License activation and validation use Lemon Squeezy's licensing API. These operations send the license key, a random installation label or instance identifier, and the product identity needed for licensing. The entitlement does not use a hardware fingerprint.

The local entitlement cache retains the license key and installation secret under the existing PREFIX per-user policy. This is local software protection, not a hardware-backed vault or protection from an administrator who controls the machine. Keep the installation and operating-system account private.

Engine receipts can retain local source before and after a correction, and the optional operator console can retain local records. Review local data before sharing an issue or diagnostic archive.

Read the [published PREFIX privacy policy](https://fast-industries-prefix.steven-k-ratushniak.chatgpt.site/legal/prefix/privacy/).
