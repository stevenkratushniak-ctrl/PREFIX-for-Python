# PREFIX Operator Trust Evolution

PREFIX earns trust by exposing enough structure to be inspectable without becoming noisy.

## Current Trust Surfaces

- status bar lane signal
- output-channel proof surface
- AST hash
- token hash
- legality report
- legality score
- structural context
- continuation graph
- transition witness root
- receipt-backed replay
- receipt-backed rollback

## Operator Experience

The intended operator feeling is simple:

The editor does not guess. It governs.

When PREFIX applies, it explains the law.

When PREFIX advises, it shows bounded continuations.

When PREFIX refuses, it preserves trust.

## Next Trust Step

The next operator-facing improvement should be a quiet local inspector for the latest transition witness. It should remain optional and compact.
