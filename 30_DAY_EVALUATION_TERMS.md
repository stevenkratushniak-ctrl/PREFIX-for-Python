# 30-DAY EVALUATION TERMS

## Evaluation Window

Standard evaluation term: `30` days from operator onboarding.

## Evaluation Scope

The evaluation covers only the bounded deterministic release surface of `PREFIX for Python`.

It does not promise:

- broad language support
- probabilistic suggestion behavior
- general-purpose code generation
- copilot-style assistance

## Operator Access Includes

- canonical release bundle
- install and demo guidance
- operator support contact path
- evaluation checkpoints
- pricing and conversion review path

## Operator Responsibilities

- complete onboarding steps
- run the first-day demo flow
- use the product on real bounded Python workflows
- share high-signal operational feedback
- participate in scheduled check-ins when requested

## Support Expectations

During the 30-day window, the operator receives:

- launch packet materials
- trust-surface explanations
- direct response path for install, receipts, rollback, replay, and refusal questions

## End-of-Term Outcomes

At the end of 30 days:

- convert to Pro, Team, or Enterprise path
- extend evaluation selectively if justified
- conclude the pilot if the fit is not strong

## Commercial Guardrail

The evaluation should demonstrate premium infrastructure value.

It should not be presented as indefinite free usage.
