# Resolution Evidence Model
RESOLVED_STANDARD: stable pinned supported environment; standard/classified finder supplies ModuleSpec.
RESOLVED_BUILTIN / RESOLVED_FROZEN: standard finder evidence.
RESOLVED_LOCATION: spec origin/location evidence; loading remains unproven.
NAMESPACE_PACKAGE: origin None with package search portions; portions recorded in order.
ABSENT_IN_PINNED_ENVIRONMENT: only when stable supported pinned standard/classified resolution surface returns no spec for the request.
RESOLVED_BY_CUSTOM_FINDER: spec exists but unmodeled custom finder materially participates; record finder/spec, narrow claim.
AMBIGUOUS_ENVIRONMENT_DEPENDENT: known pinned environments or unstable relevant inputs disagree.
PACKAGE_CONTEXT_REQUIRED: relative/submodule resolution lacks parent package context/path.
UNSUPPORTED_ENVIRONMENT: outside CPython 3.12 authority.
OUTSIDE_CURRENT_AUTHORITY: stable evidence cannot be formed.

find_spec evidence proves discovery under the observed machinery, not successful module execution. None means not found under that pinned search state; never “does not exist anywhere.”
