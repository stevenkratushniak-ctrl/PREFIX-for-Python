# Environment Reverse Taxonomy
A resolved built-in/frozen claim becomes unresolved if interpreter identity changes or the governing standard finder surface is replaced. A path-backed resolution changes if ordered path inputs, relevant CWD, path hooks, parent package __path__, finder ordering or the supplying artifact changes.

A namespace resolution changes when any contributing portion or parent search input changes; plurality of portions is an admissible namespace property, not an error.

ABSENT_IN_PINNED_ENVIRONMENT can become resolved through a built-in/frozen match, a path-backed module/package, namespace portion, custom finder, relevant path/package-context change, or another pinned environment. None is performed here.

CUSTOM_FINDER_ACTIVE becomes standard-authoritative only when the custom component is removed from the relevant search or separately mapped. PACKAGE_CONTEXT_REQUIRED becomes decidable when the parent package identity and relevant __path__ are pinned.

A returned spec can become load-failing through loader/module execution behavior; therefore RESOLVED does not reverse-map to guaranteed runtime success.
