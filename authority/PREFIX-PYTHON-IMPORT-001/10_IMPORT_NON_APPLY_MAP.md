# Import Non-APPLY Map
ADVISE: multiple bounded grammar successors; multiple mechanically established module/symbol alternatives; module present in another explicitly known pinned environment.

ANALYZE: unresolved module in pinned standard-resolver snapshot; statically absent requested symbol without proof of runtime absence; alias/binding collision; relative import lacking package context; spec found but load not proven.

REFUSE/OUTSIDE: custom/unknown finder semantics; dynamic __path__; generated/network module; runtime-only re-export; monkey-patched import behavior; unpinned environment; implicit package installation/dependency solving.

Unique spelling similarity, unique filesystem near-match or unique static-symbol near-match never establishes source APPLY.
